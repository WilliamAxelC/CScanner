## Security & Update Controls

| ID / Fingerprint | Baseline Severity / Status | Issue Summary | Remediation Implemented |
| --- | --- | --- | --- |
| `cscanner/pdf-and-jpeg-redaction-bypass` | **HIGH** (`confirmed`) | Redaction boxes only drew an overlay rectangle in PDFs while preserving raw underlying JPEG pixels and all overlapping OCR text blocks; JPEG export omitted redactions cleanly. | `reencodeJpegForExport` burns solid redaction rectangles directly into exported pixels in [processor.web.ts](src/services/image/processor.web.ts) (Canvas) and [processor.native.ts](src/services/image/processor.native.ts) / [CScannerMlkitModule.kt](modules/cscanner-mlkit/android/src/main/java/com/cscanner/mlkit/CScannerMlkitModule.kt) (`redactImage`). `filterRedactedOcrBlocks` in [pdfExporter.ts](src/services/pdf/pdfExporter.ts) strips overlapping OCR blocks from searchable PDF streams. |
| `cscanner/sync-manifest-traversal-and-conflict-bypass` | **HIGH** (`confirmed`) | Untrusted Google Drive `doc-*.json` manifests allowed path-traversal asset IDs into `saveImageBytes`/`deleteImage`, mismatch bypass between filename ID and `manifest.id`, and overwriting `Page` rows belonging to another document. | Added `assertSafeAssetId` and `validateRemoteManifest` in [security.ts](src/utils/security.ts), enforced filename/`manifest.id` match and cross-document page ID re-keying in [syncEngine.ts](src/services/sync/syncEngine.ts), and restricted asset filenames + managed directories (`isManagedImageUri`) in [database.native.ts](src/storage/database.native.ts) and [database.web.ts](src/storage/database.web.ts). |
| `cscanner/web-oauth-token-localstorage-shared-origin` | **HIGH** (`confirmed`) | Google OAuth access token and email were written to `window.localStorage` under shared origin `https://cuang.dev`, exposing bearer tokens to any sibling `/projects/*` page; `signOut` skipped remote revocation. | Web OAuth tokens in [googleAuth.ts](src/services/sync/googleAuth.ts) now remain strictly in volatile memory, actively deleting any legacy `cscanner_google_token_v1` `localStorage` entry on load/save, and `signOut` invokes `revokeGoogleToken()` (`oauth2.googleapis.com/revoke`). |
| `cscanner/deeplink-prototype-lookup-crash` | **LOW** (`confirmed`) | Deep links such as `cscanner://doc/constructor/edit/1` indexed plain `Record<string, Page[]>` directly without `hasOwnProperty` or parent document checks, throwing `TypeError`; `/scan` also auto-launched native scanners on mount without checking origin. | Added prototype-safe `getPagesForDoc` helper in [security.ts](src/utils/security.ts) and wired across [app/doc/[id].tsx](app/doc/[id].tsx), [app/doc/[id]/edit/[pageId].tsx](app/doc/[id]/edit/[pageId].tsx), [app/doc/[id]/ocr.tsx](app/doc/[id]/ocr.tsx), and [app/doc/[id]/export.tsx](app/doc/[id]/export.tsx). [app/scan.tsx](app/scan.tsx) now requires explicit `fromApp: '1'` before auto-launching ML Kit / gallery import and validates `documentId` against stored documents. |
| `cscanner/drive-api-mime-injection-and-weak-boundary` | **LOW** (`confirmed`) | Unvalidated `mimeType` header interpolation, `Math.random()` multipart boundaries, unescaped Drive query literals, and raw HTTP response errors in errors/logs. | Enforced `assertValidMimeType`, `escapeDriveQueryValue`, CSPRNG `generateId()` multipart boundaries, and sanitized HTTP error messages in [driveApi.ts](src/services/sync/driveApi.ts) and [syncEngine.ts](src/services/sync/syncEngine.ts). |
| `cscanner/pdf-password-trim-desync` | **LOW** (`confirmed`) | Whitespace-only passwords passed Export UI checks and caused `buildPdfBytes` to silently skip encryption; `ownerPassword` reused `userPassword`. | [pdfExporter.ts](src/services/pdf/pdfExporter.ts) rejects blank/whitespace-only passwords when encryption is requested, preserves exact user password input without silent trimming, and assigns a random per-document `ownerPassword`. |
| `cscanner/native-mlkit-bridge-path-confinement-and-oom` | `needs_validation` -> Hardened + Kotlin unit tested in CI | Native Android bridge omitted canonical root confinement, allowed unbounded bitmap decode (`OOM`), omitted `NaN` clamping in `warpQuadBitmap`, and copied scan results unboundedly. | Added `resolveSafeOutputFile`, `isAllowedInputUri`, `isInsideAllowedRoots` (excluding `databases`/`shared_prefs`), 2-pass `calculateInSampleSize` (`MAX_BITMAP_DIM = 4096`), `safeClamp01`, `copyBounded` (`25 MB`), clamped `pageLimit` (`1..50`), and sanitized promise rejections in [CScannerMlkitModule.kt](modules/cscanner-mlkit/android/src/main/java/com/cscanner/mlkit/CScannerMlkitModule.kt) + unit tests in [CScannerMlkitModuleTest.kt](modules/cscanner-mlkit/android/src/test/java/com/cscanner/mlkit/CScannerMlkitModuleTest.kt). |
| `cscanner/android-allow-backup-and-permissions` | `needs_validation` -> Hardened + CI `aapt2` gated | Default `allowBackup=true` and `expo-image-picker` injecting `RECORD_AUDIO` permission on Android prebuild. | Configured `allowBackup: false`, `usesCleartextTraffic: false`, `blockedPermissions: ["android.permission.RECORD_AUDIO"]`, and `expo-image-picker` `microphonePermission: false` in [app.json](app.json), plus `aapt2 dump permissions` and `allowBackup=false` assertions in [.github/workflows/build.yml](.github/workflows/build.yml). |
| `cscanner/nginx-missing-security-headers-and-inline-sw-script` | `needs_validation` -> Hardened + Live E2E verified | Inline SW bootstrap `<script>` prevented strict `script-src`; nested nginx `location` blocks lacked `Content-Security-Policy`, `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, and `Permissions-Policy`. | Extracted external `sw-register.js` and stripped `.map` files in [scripts/build-pwa.mjs](scripts/build-pwa.mjs), added security headers to all CScanner & download/APK nested `location` blocks in [scripts/deploy-cuang.sh](scripts/deploy-cuang.sh), and updated external links (`rel="noopener noreferrer"`) in [scripts/generate-download-page.mjs](scripts/generate-download-page.mjs). |
| `cscanner/ci-ephemeral-signing-and-token-permissions` | `needs_validation` -> Hardened + Owner secret option | Workflow lacked explicit least-privilege `GITHUB_TOKEN` permissions and always fell back to an ephemeral keystore. | Added top-level and per-job `permissions: contents: read` (only `release` tag job uses `contents: write`) and optional persistent `ANDROID_KEYSTORE_*` secrets support in [.github/workflows/build.yml](.github/workflows/build.yml). Note: persistent release signing key secrets and branch protection settings remain repository-owner configuration items. |
| `cscanner/web-ocr-third-party-cdn-worker` | `needs_validation` -> Bounded + Documented | Web Tesseract worker downloads WASM/traineddata from `cdn.jsdelivr.net` and cached for 90 days. | Reduced Workbox CDN cache TTL from 90 days to 14 days (`maxEntries: 16`) in [workbox-config.js](workbox-config.js), restricted CSP `script-src`/`worker-src`/`connect-src` in [scripts/deploy-cuang.sh](scripts/deploy-cuang.sh), and documented exact Web OCR CDN behavior in [app/privacy.tsx](app/privacy.tsx). |
| In-app APK updater hardening | Defense-in-depth | Sideloaded self-updater uses `REQUEST_INSTALL_PACKAGES`. | Strict manifest origin check (`https://cuang.dev/` only, `.apk`, no query/hash), 64-char hex SHA-256 checksum verification (`computeSha256Hex`) before package inspection, `PackageManager.getPackageArchiveInfo` verification (`dev.cuang.cscanner` and exact `versionCode`), canonical `<cacheDir>/updates/*.apk` confinement in [CScannerMlkitModule.kt](modules/cscanner-mlkit/android/src/main/java/com/cscanner/mlkit/CScannerMlkitModule.kt), and `FileProvider` scoped sharing in [appUpdate.ts](src/services/updates/appUpdate.ts). |
